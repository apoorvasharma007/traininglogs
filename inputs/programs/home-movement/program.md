# Home Movement

Ad-hoc, unprogrammed movement-general training — no phase or week, wherever it
happens: juggling, reaction drills, shadow boxing, ab-strap core, stretching,
kettlebell/dumbbell work, and calisthenics/gymnastics-rings skill work (home or gym
alike, as long as it isn't part of a formal phase/week program — those keep their
own program name instead). Each session's `focus` names the day's emphasis
(e.g. "Skills + Core", "Rings + Muscle-Up Prep").

**Conventions:** skill runs and skill attempts log as sets (juggling catches = reps;
muscle-up-style attempts = full reps for clean, partial for failed); static holds and
timed rounds log as duration; measured reaction times live in set notes. These same
conventions also apply when a calisthenics/rings exercise is mixed into a real
structured gym session — see `templates/gym-mixed-calisthenics-example.md`.

**To log an ad-hoc session:** copy `templates/home-movement-template.md` to a new
file here (e.g. `2026-07-19.md`), fill it in, then run
`traininglogs log inputs/programs/home-movement/2026-07-19.md`. Two worked examples:
`templates/home-movement-example.md` (juggling, reaction, L-sit, shadow boxing,
KB) and `templates/home-movement-example-rings.md` (rings/muscle-up-prep flavor).
