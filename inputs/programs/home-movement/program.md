# Home Movement

Unprogrammed home and movement-general training: calisthenics skill work, juggling,
reaction drills, shadow boxing, parallettes, ab-strap core, stretching, and
kettlebell/dumbbell work at home. Sessions are ad-hoc — no phases or weeks; each
session's `focus` names the day's domain.

**Conventions:** skill runs log as sets (juggling catches = reps, best run = best set);
static holds and rounds log as duration; measured reaction times live in set notes.
