# Bodybuilding Transformation System

A hypertrophy-focused PPL+Upper/Lower hybrid. Each phase runs 12 weeks split into two blocks — exercises rotate at week 7 to manage joint fatigue and introduce new stimulus.

**Structure:** 5 sessions/week — Push, Pull, Legs (hypertrophy), Upper Strength, Lower Strength  
**Phases:** Phase 2 (complete), Phase 3 (complete)  
**Deload:** Week 6 and Week 12 of each phase

---

## Block 1 — Weeks 1–6 (Foundation)

| Session | Exercises |
|---|---|
| Push Hypertrophy | Barbell Bench Press, Seated DB Shoulder Press, Bottom Half DB Flye, High Cable Lateral Raise, Overhead Cable Tricep Extension Bar, Cable Tricep Kickback Upright, Hanging Leg Raise, Wrist Flexion/Extension DB Curl, Forearm Preacher Curl |
| Pull Hypertrophy | Neutral Grip Lat Pulldown, Chest Supported Machine Row, Seated Cable Row Wide Grip, 1 Arm 45° Cable Rear Fly, Cable Paused Shrug, EZ Bar Cable Curl, EZ Bar Preacher Curl |
| Legs Hypertrophy | Leg Press, Seated Leg Curl, DB Bulgarian Split Squat, Leg Extension, Cable Hip Adduction, Cable Hip Abduction, Standing Calf Raise, Tibialis Raise |
| Upper Strength | Incline DB Press 45°, Pec Dec Single Arm, Wide Grip Pullup, High Cable Lateral Raise, Deficit Pendlay Row, Overhead Cable Tricep Extension Bar, Bayesian Cable Curl, Wrist Flexion/Extension, Forearm Preacher Curl |
| Lower Strength | Seated Leg Hamstring Curl, Smith Machine Squat, Barbell Romanian Deadlift, Leg Extension, Standing Calf Raise, Cable Crunch, Tibialis Raise |
